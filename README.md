### Step 3: Enable GitHub Pages

1. Opened the repository settings.
2. Navigated to **Settings → Pages**.
3. Selected:

   * Source: **Deploy from a branch**
   * Branch: **main**
   * Folder: **/(root)**
4. Saved the configuration.
